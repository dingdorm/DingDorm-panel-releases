# DingDorm · versiones del programa de escritorio

Instaladores del programa **DingDorm** para Windows (paneles de Recepción, Dirección, Admisiones, Comedor y Manitas).

Los programas instalados miran aquí si hay una versión nueva, la descargan solos y avisan para reiniciar. Para instalarlo por primera vez, descarga el `DingDorm Setup x.y.z.exe` de la última versión en [Releases](../../releases/latest).

El código no está en este repositorio.
